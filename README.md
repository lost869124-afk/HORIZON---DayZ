# HORIZON — Менеджер серверов DayZ

**Управление. Автоматизация. Контроль.**

HORIZON — локальная панель управления серверами DayZ, созданная для удобного администрирования, автоматизации рутинных задач и контроля состояния игровых серверов.

Программа позволяет управлять несколькими серверами из единого интерфейса, настраивать автоматические перезапуски, работать с модификациями, контролировать игроков через RCON и управлять конфигурациями серверов.

HORIZON ориентирован на владельцев игровых серверов и системных администраторов, которым нужен единый инструмент для повседневного управления инфраструктурой DayZ.

---

## Основные возможности

### Управление серверами
- Создание и удаление профилей серверов.
- Запуск, остановка и перезапуск серверов.
- Одновременное управление несколькими серверами.
- Настройка параметров запуска.

### Автоматизация
- Автоматические перезапуски по расписанию.
- Предупреждения игроков перед перезапуском.
- Отложенные и ручные перезапуски.
- Восстановление после аварийного завершения.

### Мониторинг
- Отображение состояния серверов.
- Мониторинг FPS и количества игроков.
- Отображение времени работы серверов.
- Просмотр журналов событий.

### Управление модификациями
- Работа с модификациями Steam Workshop.
- Загрузка и обновление модификаций через SteamCMD.
- Синхронизация модификаций с серверами.
- Проверка ключей модификаций.

### BattlEye RCON
- Просмотр списка игроков.
- Получение SteamID игроков.
- Кик и бан игроков.
- Блокировка и разблокировка сервера.
- Отправка игровых сообщений.

### Настройки и конфигурации
- Управление параметрами запуска.
- Настройка портов, карты и миссии.
- Настройка RCON.
- Работа с конфигурационными файлами DayZ.

### Управление игровым движком
- Использование общей мастер-копии DayZ.
- Создание отдельных экземпляров серверов.
- Оптимизация хранения игровых файлов.

### Редактор экономики
- Работа с XML-файлами экономики DayZ.
- Редактирование основных параметров экономики.
- Проверка конфигурационных файлов.
- Создание резервных копий.

## Технологии

- Python 3.10+
- Стандартная библиотека Python.
- Локальный веб-интерфейс.
- Windows — основная платформа.

## Установка и запуск

1. Скачайте проект из репозитория.
2. Убедитесь, что установлен Python 3.10 или новее.
3. Запустите файл `start.bat`.
4. Откройте веб-интерфейс в браузере.

## Безопасность

По умолчанию веб-интерфейс работает локально и доступен по адресу `127.0.0.1:8080`.

Не публикуйте конфигурационные файлы, содержащие пароли, токены, данные RCON и другие конфиденциальные сведения.
